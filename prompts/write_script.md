## 创作要求

1. **完整叙事弧线**（必须四段齐全，按顺序输出）：
   - **钩子（约 5 秒）**：1 句话，制造好奇 / 抛出价值 / 抛出问题
   - **是什么（约 10 秒）**：2-3 句话，交代主题、对象、背景
   - **怎么用 / 亮点（约 30-50 秒）**：4-8 句话，逐条展示视频里最值钱的内容
   - **行动呼吁（约 5 秒）**：1 句话，引导关注 / 试用 / 看完整版

2. **句式规范**：
   - 每句 12-25 个汉字，语气连贯但不复杂；不要长难句
   - 总字数按"4 字/秒"估算，控制在 `target_duration * 4` 字上下 ±10%
   - 口吻服从 `tone` 参数：
     - `casual`：轻快口语，可以使用"咱们"、"它"、"很顶"等
     - `formal`：客观陈述，避免感叹词
     - `hype`：煽动性短视频风，多用感叹与短句

3. **画面绑定（重要）**：
   - 每句必须指定 `frame_indices`：1-2 个帧下标，表示这句话朗读时画面应该显示的帧
   - 钩子 / 行动呼吁建议绑标志性画面（开头 / 结尾帧）
   - 亮点段每句尽量绑该亮点对应时段的帧，避免画面与解说脱节
   - 帧下标必须落在 `[0, num_frames - 1]` 区间内

4. **情绪标注 `emotion`**：每句从 `neutral|excited|serious|warm` 中四选一，给 TTS 提供调度参考；钩子常用 `excited`，知识讲解多用 `neutral` 或 `serious`，结尾建议 `warm`。

5. **标题 `title`**：1 句不超过 20 字，能独立挂在短视频封面用。

## 输出 JSON Schema

只输出 JSON 对象本身，不要 markdown 代码块、不要前后说明文字：

```
{
  "title": "<string, <= 20 chars>",
  "tone": "casual" | "formal" | "hype",
  "lines": [
    {
      "text": "<string, 12-25 chars>",
      "emotion": "neutral" | "excited" | "serious" | "warm",
      "frame_indices": [<int>, ...]
    },
    ...
  ]
}
```

## 硬约束

- 必须输出合法 JSON，字段名与 Schema 完全一致
- `lines` 至少 6 句，最多 16 句
- 每句 `text` 长度严格 ≤ 50 字
- 每句 `frame_indices` 至少 1 个、最多 2 个，且全部落在合法下标范围内
- 不要复用同一个 frame_index 超过 2 次（避免画面单调）
- 不要带 markdown 围栏、注释或 Schema 之外的字段
